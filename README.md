# HALLWAYS 0.1

Primer prototipo de HALLWAYS, creado con Godot 4 y GDScript.

## Incluye
- Creador de personaje: nombre, pronombres, tono de piel, color y estilo de pelo y camiseta.
- MC independiente de Jacqueline.
- Pasillo lateral dibujado con formas originales.
- Movimiento con A/D o flechas.
- Un NPC de prueba con opciones de diálogo.
- Guardado local de la apariencia en `user://hallways_player.cfg`.

## Ejecutar
1. Instala Godot 4.
2. Descomprime el ZIP.
3. Abre Godot y elige Importar.
4. Selecciona el archivo `project.godot`.
5. Ejecuta el proyecto con F6 o F5.

## Controles
- A / D o flechas: moverse.
- E: hablar cuando estés cerca del NPC.
- Android/táctil: ◀ y ▶ para moverse; HABLAR para interactuar.
- Escape: cerrar el diálogo.
- Pantalla táctil: botones ◀ y ▶ para moverse, HABLAR para interactuar y botones del creador.

## Estado
Es un prototipo inicial. Los gráficos son placeholders vectoriales dibujados por código, no arte final.
